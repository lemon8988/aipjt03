실행 시각: 2026-11-20 00:09 KST · 실제 외부 API 호출 · 모든 호출이 예외 없이 아래 형식으로 반환됨

## 등록된 Tool 명세 (이름 · 종류 · 설명 · 입력 스키마)

### geo_loc (external)
- 설명: 사용자가 말한 위치(역명·동네·건물)를 좌표로 바꿔야 할 때 쓴다. 같은 이름이 여러 곳이면 AMBIGUOUS 로 후보를 돌려준다.
- 입력 스키마: `{"type": "object", "properties": {"q": {"type": "string", "description": "위치 이름"}, "size": {"type": "integer", "default": 5}}, "required": ["q"]}`

### find_stn (external)
- 설명: 참여자 좌표의 중심 주변에서 만남 후보 지하철역이 필요할 때 쓴다.
- 입력 스키마: `{"type": "object", "properties": {"x": {"type": "number", "description": "경도"}, "y": {"type": "number", "description": "위도"}, "radius_m": {"type": "integer", "default": 3000}, "size": {"type": "integer", "default": 15}}, "required": ["x", "y"]}`

### find_spot (external)
- 설명: 후보 역 주변의 음식점·카페·문화시설·관광명소를 찾거나 반경 내 개수가 필요할 때 쓴다. 어떤 영화·상영 정보 같은 것은 알려주지 않는다.
- 입력 스키마: `{"type": "object", "properties": {"x": {"type": "number", "description": "경도"}, "y": {"type": "number", "description": "위도"}, "radius_m": {"type": "integer", "default": 500}, "cat": {"type": "string", "enum": ["음식점", "카페", "문화시설", "관광명소"]}, "q": {"type": "string"}, "size": {"type": "integer", "default": 5}}, "required": ["x", "y", "cat"]}`

### get_route (external)
- 설명: 참여자 위치에서 후보 역까지의 대중교통 이동시간(분)과 환승 수가 필요할 때 쓴다. 조회 시점 기준이며 약속 시각의 운행과 다를 수 있다.
- 입력 스키마: `{"type": "object", "properties": {"from": {"type": "object", "properties": {"x": {"type": "number"}, "y": {"type": "number"}}, "required": ["x", "y"]}, "to": {"type": "object", "properties": {"x": {"type": "number"}, "y": {"type": "number"}}, "required": ["x", "y"]}}, "required": ["from", "to"]}`

### get_wx (external)
- 설명: 약속 날짜의 강수확률로 실내·야외 장소를 가를 때 쓴다. 날짜가 예보 범위 밖이면 OUT_OF_RANGE.
- 입력 스키마: `{"type": "object", "properties": {"x": {"type": "number"}, "y": {"type": "number"}, "date": {"type": "string", "description": "YYYY-MM-DD"}}, "required": ["x", "y", "date"]}`
